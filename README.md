# Keerthana Vinoth — Developer Portfolio

A responsive personal portfolio built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript.

## Run locally
Open `index.html` with VS Code Live Server.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `keerthana-portfolio`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. The expected site URL is `https://keerthanavinoth2003-maker.github.io/keerthana-portfolio/`.

## Privacy choices
- Personal mobile number and personal email address are not included in this public version.
- Contact options point to the public LinkedIn and GitHub profiles.
- No placeholder or unfinished resume PDF is included. Add a genuine resume PDF only after it is ready.

## SEO
Includes a descriptive page title, meta description, relevant keywords, canonical URL, Open Graph/Twitter metadata, Person structured data, `robots.txt`, and `sitemap.xml`.

If you choose a different repository name or custom domain, update the canonical and sitemap URLs in `index.html` and `sitemap.xml`.

## Assets
Bootstrap, Bootstrap Icons and Google Fonts are loaded from public CDNs, so an internet connection is needed for those assets.
